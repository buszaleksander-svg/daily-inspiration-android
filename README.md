# Daily Inspiration ✨

Daily Inspiration is a minimalist Android app built with Kotlin and Jetpack Compose.

The app delivers inspirational quotes with a clean and modern UI, allowing users to save favorite quotes and track quote history.

## 📱 Google Play

Download the app here:

https://play.google.com/store/apps/details?id=com.klubbforsaljning.dailyinspiration

---

## 🚀 Features

- Random inspirational quotes
- Save quotes to Favorites
- Quote History persistence
- Remove favorites
- Clear History functionality
- Smooth animations
- Minimalistic modern UI
- Local persistence using SharedPreferences

---

## 🛠 Tech Stack

- Kotlin
- Jetpack Compose
- Navigation Component
- SharedPreferences
- Android Studio
